Connectivity Checker Help

                    
                

                

                    
This tool perform connectivity check using TCP Dump. It connects through SSH to Probe Server
                        selected on drop down.
                        You can filter by:

                    
    
                        
  • Interface: Example: eth0, any
    • 
                        
  • IP: Source/destination IP filter
    • 
                        
  • Port: Optional port filter
    • 
                        
  • Protocol: TCP, UDP, ICMP, or Any
    • 
                        
  • Duration: Capture time in seconds
    • 
                        
  • Packet Count: Optional limit on packet capture
    • 
                    

                    
Example:

                    
tcpdump -vvv -nn  host 8.8.8.8 and  tcp

                    
Button Functionality:

                    
    
                        
  • Validate: Checks if all form fields are valid and gives feedback. If
                            everything is correct, a tcpdump command is generated.
    • 
                        
  • Start Capture: Initiates the packet capture process based on the validated
                            parameters. Starts tcpdump with your chosen filters.
    • 
                        
  • Stop Capture: Stops an ongoing packet capture session (will only be enabled
                            once the capture is running).
